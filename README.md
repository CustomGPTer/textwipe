# TextWipe

TextWipe lets you text your own Android phone a command word and your PIN to lock it, ring it at full volume, get a GPS map link back, wipe the folders you chose or factory reset it. No internet permission, no account, no adverts.

Website: https://customgpter.github.io/textwipe/

Download: https://github.com/CustomGPTer/textwipe/releases/latest/download/TextWipe.apk
